# Advanced Manufacturing Company of America (Amca)

> Amca is an El Segundo, California aerospace and defense manufacturer founded in 2024. It designs
> and builds physical flight hardware — human-machine interface and cockpit switch panels, avionics
> and flight-control electronics, hydraulic actuation, and power electronics — for platforms
> including the F-35 and commercial widebody and narrowbody aircraft.

## API surface

Amca publishes **no public API**. As of 2026-09-07 there is no developer portal, no API reference,
no OpenAPI/AsyncAPI/GraphQL/gRPC/WSDL contract, no MCP server, and no A2A agent card. There are no
`api.`, `docs.`, `developer.`, `app.` or `portal.` subdomains in DNS for amca.com, and every
`/.well-known/` path returns 404. The company's RAPID platform is an internal design-to-production
workflow, not a customer-facing developer product. Do not attempt to call an Amca API; there is
none to call.

Note: amca.com is a Next.js site whose catch-all returns HTTP 200 with an HTML shell for unknown
top-level paths (e.g. /openapi.json, /docs, /graphql). Those are soft-404s, not documents.
